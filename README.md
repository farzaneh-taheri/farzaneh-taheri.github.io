# فرطا | سایت رسمی استودیو امنیت و پایداری وردپرس و ووکامرس

نسخه‌ی اولیه‌ی وب‌سایت فرطا (farta.ir): ۲۰ صفحه‌ی فارسی راست‌به‌چپ با تم تاریک «فضا و امنیت»، ساخته‌شده با Astro و Tailwind CSS.
خروجی پروژه کاملاً **استاتیک** است و فقط فرم تماس به یک اسکریپت PHP کوچک نیاز دارد، پس روی هاست‌های PHP-محور (مثل نت‌افزار) بدون Node.js اجرا می‌شود.

## صفحه‌ها

صفحه‌ی اصلی، ۴ صفحه‌ی حوزه‌ی خدمات (`category-*`)، ۸ صفحه‌ی خدمت (`service-*`)، نمونه گزارش‌ها (`evidence`)، درباره ما، پرسش‌های متداول، تماس (با مسیر «اختلال فوری»)، تشکر، حریم خصوصی و قوانین.

## اجرا روی سیستم خودتان

پیش‌نیاز: Node.js نسخه‌ی ۲۲.۱۲ یا بالاتر.

```sh
npm install
npm run dev        # http://localhost:4321  (با به‌روزرسانی آنی)
npm run build      # خروجی نهایی در پوشه‌ی dist
npm run preview    # نمایش خروجی بیلدشده
```

در حالت `npm run dev` سرور PHP وجود ندارد؛ ارسال فرم مستقیم به صفحه‌ی تشکر می‌رود تا مسیرش قابل پیش‌نمایش باشد. ارسال واقعی ایمیل فقط روی هاست کار می‌کند.

## ساختار

```text
public/
  contact.php      دریافت فرم و ارسال ایمیل (روی هاست اجرا می‌شود)
  .htaccess        HTTPS اجباری، بستن لیست پوشه‌ها و فایل‌های نقطه‌دار/لاگ
src/
  pages/           صفحه‌ها (هر فایل یک مسیر)
  components/      هدر، فوتر، نوار بالا، نوار پایین موبایل
  layouts/         چیدمان مشترک + انیمیشن‌ها و پس‌زمینه‌ی فضایی
  data/site.ts     داده‌ی منوها
  styles/global.css  تم، انیمیشن‌ها و استایل محتوا
```

## انتشار روی هاست (نت‌افزار)

1. `npm run build`
2. **محتوای** پوشه‌ی `dist` (نه خود پوشه) را در روت هاست یا ساب‌دامین آپلود کنید.
3. نمایش فایل‌های مخفی را در FTP/فایل‌منیجر روشن کنید تا `.htaccess` هم آپلود شود.
4. یک درخواست واقعی از فرم بفرستید و رسیدن ایمیل (`info@farta.ir`) را تست کنید.

لینک‌های سایت مسیر مطلق دارند (`/contact/`)؛ سایت باید روی روت یک دامنه یا ساب‌دامین باشد، نه داخل یک زیرپوشه.
